## 4. איך לבצע ולפרוס תיקונים (נקודות טכניות)

- **כל הטקסטים למשתמש** נמצאים ב-`locales.js` (עברית = שפת בסיס; יש גם en/es/ru). באג שפה = בדרך כלל מחרוזת קשיחה ב-`index.html`/JS או מפתח חסר ב-`locales.js`.
- **UI** נבנה מ-`app.js → ui/…` ל-`app.bundle.js` דרך `tools/bundle.js`. **לא לערוך `app.bundle.js` ידנית.**
- **בנייה:** `npm run build` (bundle + css + עדכון hash של ה-cache ב-sw.js). חובה גם לקדם את `?v=` ב-`index.html` אחרת שינויים לא מגיעים למשתמשים.
- **אנדרואיד (כדי שהבודקים יקבלו את התיקון):** `npm run cap-build` → `npx cap sync` → build AAB (`build_aab.ps1`) → העלאה לטראק הבדיקה ב-Play Console. deploy ל-Netlify מעדכן רק את גרסת הווב.
- **בדיקות:** `npm test` (vitest), `npm run test:e2e` (Playwright), `npm run lint`.
- **סביבת פיתוח AI:** Antigravity — כותבים לו הנחיה מדויקת (קובץ + שורות + מה לשנות + איך לבדוק), הוא מבצע, ואז מאמתים את ה-diff וה-build.
